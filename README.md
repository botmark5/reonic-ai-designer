# Reonic AI Designer (thinc! Hack Munich 2026)

AI design engine that proposes PV, battery, wallbox and heat pump for a home the way an installer's planner would.
`engine/` = Python data pipeline, model, FastAPI · `web/` = Next.js app · `docs/` = plan, decisions, API contract.
Setup and approach: see docs/. Raw data lives in `data/raw/` and is never committed.
